#### New Features
1. Redesigned and simplifed the Carrier page in the portal, adding support for additional carrier authentication features.
1. Add support for [STT Latency metrics](https://github.com/jambonz/jambonz-feature-server/issues/1204)
1. Add support for Deepgram Flux STT.
1. Add support for Gladia STT.
1. Add support for Soundhound STT.
1. Add support for AssemblyAI v3 STT.
1. Add support for Deepgram EU hosted endpoint.
1. Add support for additinonal ElevenLabs hosted endpoints.
1. Add support for Cartesia Sonic-3 streaming TTS model.
1. Add support for Resemble TTS.
1. Add [additional languages and phrases](https://github.com/jambonz/jambonz-feature-server/pull/1367) to voicemail greeting file.
1. Config verb can now be used to disable tts caching for the entire call.
1. New `distributeDtmf` property added to conference verb to enable DTMF distribution to all conference members.
1. Add support for tel scheme in referTo property of dial verb.
1. Add new Alert verb
