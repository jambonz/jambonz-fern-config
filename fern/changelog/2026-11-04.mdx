This entry adds Sarvam AI as a text-to-speech and speech-to-text vendor, for Indian English,
Hindi and other Indic languages.

#### New Features & Improvements

1. **Sarvam AI text-to-speech** — `sarvam` is available as a TTS vendor, with streaming TTS and
   speech credentials in the portal and API. The Bulbul models `bulbul:v4-flash` (default),
   `bulbul:v3` and `bulbul:v2` cover eleven Indian languages, and the portal lists the
   `bulbul:v4-flash` personas by language. Options are `pace`, `pitch`, `loudness`,
   `temperature`, `enable_preprocessing` and `dict_id`, plus buffering controls for
   streaming. See [Sarvam AI](/guides/features/tts-vendor-settings/sarvam).
1. **Sarvam AI speech-to-text** — the same `sarvam` credential serves realtime speech
   recognition with `saaras:v3-realtime` (default) or `saaras:v4`, in 23 Indian languages or
   with automatic language detection. Sarvam signals the start and end of speech and returns
   a final transcript after each pause. `sarvamOptions` sets the stream type, the transcript
   mode (including translation to English), the voice activity settings, a prompt and, for
   `saaras:v4`, key terms. See [recognizer](/verbs/verbs/recognizer).

This entry adds Azure OpenAI as a text-to-speech and speech-to-text vendor, using the OpenAI
speech models deployed on your own Azure OpenAI resource.

#### New Features & Improvements

1. **Azure OpenAI text-to-speech** — `azureopenai` is available as a TTS vendor for one-shot
   `say` (no TTS streaming), with speech credentials in the portal and API. A credential holds the resource key, the

1. **Azure OpenAI speech-to-text** — the same `azureopenai` credential serves realtime speech
   recognition on a transcription deployment (`gpt-live-transcribe` by default, or
   `gpt-realtime-whisper`, `gpt-4o-transcribe`, `gpt-4o-mini-transcribe`).
   `azureopenaiOptions` mirrors `openaiOptions`: deployment, model family, prompt, languages,
   keywords, delay, noise reduction, turn detection and local voice activity settings. See
   [recognizer](/verbs/verbs/recognizer).

<Card title="TTS streaming" icon="regular crown" iconPosition="left">
jambonz Commercial (next release)
</Card>

TTS streaming is now limited to vendors whose websocket accepts text token by token.

#### Changes

1. **Speechify, Giggy and Mistral no longer stream TTS** — these vendors have no token-streaming
   websocket, so `say` with `stream: true` and the `agent` verb no longer use them; one-shot
   `say` is unchanged. The new HTTP-only vendors above (Azure OpenAI, Gnani, Simplismart,
   Spitch, Kokoro, Vakyam, Groq and Speechmatics) are one-shot `say` only for the same reason.
