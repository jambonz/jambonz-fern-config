---
title: Groq
subtitle: Configure jambonz to use open-weight models on Groq's LPU hardware for low TTFT.
---

Groq runs open-weight models (OpenAI's GPT-OSS, Qwen) on custom LPU silicon with very high tokens/sec, which keeps a voice agent's turns short.

The tradeoff: Groq's catalog is a small set of open-weight models. Capable, but not GPT-5 / Claude-tier on hard reasoning. Pick Groq for "look up the order, read it back" voice agents; pick Anthropic / OpenAI / Bedrock for complex reasoning.

## Get credentials

1. Sign in at [https://console.groq.com](https://console.groq.com).
2. Click **API Keys** in the sidebar (direct link: [https://console.groq.com/keys](https://console.groq.com/keys)).
3. Click **Create API Key**, name it, copy the `gsk_...` string.

<Tip>
Groq shows the key once at creation. Copy before navigating away.
</Tip>

## Configure in jambonz

In the portal: **Account → LLM Services → + Add LLM Service → Groq**.

<ParamField path="API Key" type="string" required={true}>
  The `gsk_...` key from Groq's console.
</ParamField>

<ParamField path="Base URL" type="string" required={false}>
  Defaults to `https://api.groq.com/openai/v1`. Override only for proxies — Groq's production endpoint is the default.
</ParamField>

Click **Test** to verify.

## Use in an agent verb

```js
session.agent({
  llm: {
    vendor: 'groq',
    model: 'openai/gpt-oss-120b',
    llmOptions: {
      systemPrompt: 'You are a helpful voice assistant.',
    },
  },
  stt: { vendor: 'deepgram', language: 'en-US' },
  tts: { vendor: 'cartesia', voice: 'sonic-english' },
  turnDetection: 'krisp',
  bargeIn: { enable: true },
  actionHook: '/agent-complete',
}).send();
```

## Available Models

See Groq's [supported models page](https://console.groq.com/docs/models) for the full live catalog (it churns frequently — preview models come and go). Common picks for voice agents:

| Model | Notes |
|---|---|
| `openai/gpt-oss-120b` | Best general-purpose choice on Groq; reliable tool calls |
| `openai/gpt-oss-20b` | Smaller and cheaper |
| `qwen/qwen3.8-27b` | Alternative open model with tool calling |

<Warning>
Groq retires models regularly. `llama-3.3-70b-versatile`, `llama-3.1-8b-instant` and `gemma2-9b-it` are no longer available; requests for them fail.
</Warning>

## Vendor-specific parameters

Set these in [`llmOptions.vendorParams`](/verbs/verbs/agent); they are added to the Groq request as-is. Groq rejects parameters it doesn't support with a `400`, so stick to the ones below.

| Parameter | Models | Effect |
|---|---|---|
| `reasoning_effort: "low"` | `openai/gpt-oss-20b`, `openai/gpt-oss-120b` | Less reasoning before the answer. In our tests `gpt-oss-20b` produced ~33 output tokens instead of 75–125 at the default (`"medium"`). GPT-OSS models reject `"none"` with a `400`. |
| `reasoning_effort: "none"` | `qwen/qwen3.8-27b` | Disables reasoning. Qwen on Groq doesn't return reasoning at its default setting, so there is little to gain. |

<Warning>
**Never set `reasoning_format: "raw"`.** It puts the model's reasoning, wrapped in `<think>` tags, into the reply text, and with tools enabled Groq rejects the request with a `400`.
</Warning>

## Quirks & errors

<Note>
**Tool-calling reliability scales with model size.** Test your specific tool definitions on `openai/gpt-oss-120b` and the smaller models to find the right tradeoff.
</Note>

<Note>
**Groq's catalog churns frequently.** Preview models come and go on a monthly cadence. The jambonz manifest ships a small curated set of stable models; for the full live catalog, see [Groq's models page](https://console.groq.com/docs/models) or call `listAvailableModels()` programmatically.
</Note>

<Warning>
**Rate limits are strict on the free tier.** Groq enforces tight per-minute and per-day limits if you haven't added a payment method. For production traffic, upgrade at [console.groq.com/settings/billing](https://console.groq.com/settings/billing).
</Warning>

<Warning>
**`401 invalid_api_key`** — typo or revoked key. Regenerate at [console.groq.com/keys](https://console.groq.com/keys).
</Warning>
