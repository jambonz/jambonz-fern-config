Google tuning is passed in `synthesizer.options`.

```json
{
  "verb": "say",
  "text": "Thanks for calling, how can I help you today?",
  "synthesizer": {
    "vendor": "google",
    "language": "en-US",
    "voice": "en-US-Neural2-F",
    "options": {
      "audioConfig": {
        "speakingRate": 1.1,
        "pitch": -2.0
      }
    }
  }
}
```

## Options

### audioConfig

These mirror Google's [AudioConfig](https://cloud.google.com/text-to-speech/docs/reference/rest/v1/text/synthesize#AudioConfig). They can be nested under `audioConfig` or given at the top level of `options`, and either Google's camelCase or snake_case names (`speaking_rate`, `volume_gain_db`) are accepted. Non-numeric values are ignored.

Google honours them only in some API modes: standard voices (`tts`) apply all three, HD voices (`live`) apply `speakingRate` only, and Gemini TTS ignores them — use `prompt` for style there.

<ParamField path="audioConfig.speakingRate" type="number" required={false}>
  Speaking rate. `1.0` is the voice's normal speed; Google accepts `0.25` to `4.0`.
</ParamField>

<ParamField path="audioConfig.pitch" type="number" required={false}>
  Pitch in semitones, `-20.0` to `20.0`. `0` is the voice's normal pitch.
</ParamField>

<ParamField path="audioConfig.volumeGainDb" type="number" required={false}>
  Volume gain in dB, `-96.0` to `16.0`. `0` is the voice's normal volume.
</ParamField>

### Gemini TTS

<ParamField path="model" type="string" required={false}>
  The model to use. When set, this enables Gemini TTS. Example: `gemini-2.5-flash-preview-tts`.
</ParamField>

<ParamField path="apiMode" type="string" required={false}>
  Which Google TTS API to use: `tts` (standard Cloud TTS voices), `live` (HD voices in streaming mode) or `gemini` (Gemini TTS). When omitted it is chosen for you: `gemini` if a model is set on the verb or credential, `live` for an HD voice, otherwise `tts`.
</ParamField>

<ParamField path="prompt" type="string" required={false}>
  Guidance on tone, emotion or speaking style for the generated speech. Gemini TTS only.
</ParamField>

<Note>
These options apply to the `say` verb. Google TTS used by an [agent](/verbs/verbs/agent) over the streaming path uses only the voice and language.
</Note>
