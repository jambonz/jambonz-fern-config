---
title: Microsoft
subtitle: Selecting an Azure custom neural voice per verb.
---

Microsoft (Azure) takes no tuning options, but `synthesizer.options` can point a single verb at a custom neural voice deployment instead of the voice configured on the credential.

```json
{
  "verb": "say",
  "text": "Thanks for calling, how can I help you today?",
  "synthesizer": {
    "vendor": "microsoft",
    "language": "en-US",
    "voice": "en-US-JennyNeural",
    "options": {
      "deploymentId": "your-custom-voice-deployment-id",
      "apiKey": "your-speech-resource-key",
      "region": "eastus",
      "voice": "YourCustomVoiceName"
    }
  }
}
```

## Options

<ParamField path="deploymentId" type="string" required={false}>
  Deployment (endpoint) id of the custom neural voice. Setting it switches this request to the custom voice; the other options below only take effect when it is set.
</ParamField>

<ParamField path="apiKey" type="string" required={false}>
  Key of the Speech resource that hosts the custom voice. Supply it together with `deploymentId`.
</ParamField>

<ParamField path="region" type="string" required={false}>
  Azure region of that Speech resource. Defaults to the credential's region.
</ParamField>

<ParamField path="voice" type="string" required={false}>
  Name of the custom voice. Defaults to `synthesizer.voice`.
</ParamField>

To use a custom voice for every request, configure it on the speech credential in the portal instead.
