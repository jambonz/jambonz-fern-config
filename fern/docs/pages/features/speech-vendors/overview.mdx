---

Each vendor below has its own page listing the models jambonz supports, the options jambonz passes to the vendor, and anything to watch out for.

Before using a vendor, add a speech credential for it in the portal. See [Creating speech credentials](/guides/using-the-jambonz-portal/basic-concepts/creating-speech-credentials).

## Speech-to-text

Choose the vendor in the [`recognizer`](/verbs/verbs/recognizer) of a verb (or in the application's defaults). Vendor-specific settings go in the vendor's own options object, for example `deepgramOptions` or `assemblyAiOptions`:

```json
{
  "verb": "gather",
  "input": ["speech"],
  "actionHook": "/gather",
  "recognizer": {
    "vendor": "deepgram",
    "language": "en-US",
    "deepgramOptions": {
      "model": "nova-3"
    }
  }
}
```

Many vendors also let you save a model on the speech credential. A model set on the verb takes precedence over the credential's model.

## Text-to-speech

Choose the vendor in the [`synthesizer`](/verbs/verbs/say) of a verb (or in the application's defaults). Vendor-specific tuning goes in `synthesizer.options`, which jambonz passes to the vendor unchanged:

```json
{
  "verb": "say",
  "text": "Thanks for calling, how can I help you today?",
  "synthesizer": {
    "vendor": "cartesia",
    "language": "en",
    "voice": "a0e99841-438c-4a64-b679-ae501e7d6091",
    "options": {
      "speed": -0.3,
      "emotion": "positivity:high"
    }
  }
}
```

TTS options can be set in two places:

1. **On the speech credential**, under **Extra Options** in the portal (**Account → Speech →** your credential). These apply to every request that uses the credential.
2. **On the verb**, in `synthesizer.options`. These apply to that verb only.

How the two interact depends on the verb:

- **`say`:** if the verb sets any `synthesizer.options`, the credential's Extra Options are not used for that verb. Repeat any credential settings you still want.
- **Streaming TTS** (`tts:tokens`): the two are merged one top-level field at a time, and the verb's value wins. A nested object set on the verb, such as Inworld's `audioConfig`, replaces the credential's whole object. The exception is ElevenLabs' `voice_settings`, which is merged field by field.

Use the credential for a consistent voice across an application, and the verb when one prompt needs to differ, such as a slower reading of an account number.

<Note>
jambonz does not validate `synthesizer.options`. Most vendors silently ignore a field they don't recognize, so a typo usually shows up as a setting that had no effect rather than as an error.
</Note>

`synthesizer.options` applies to the primary vendor only. A `fallbackVendor` uses its own credential's Extra Options.
