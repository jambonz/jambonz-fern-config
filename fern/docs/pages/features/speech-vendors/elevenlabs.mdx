---
title: ElevenLabs
subtitle: Speech-to-text and text-to-speech models, options and notes for ElevenLabs.
---

jambonz supports ElevenLabs for both **speech-to-text** and **text-to-speech** (vendor `elevenlabs`). Speech-to-text uses ElevenLabs' realtime Scribe API. Text-to-speech uses ElevenLabs' HTTP streaming endpoint for `say` and its websocket stream-input endpoint for [TTS streaming](/guides/features/tts-streaming). For ElevenLabs' own hosted voice agent, see the [ElevenLabs Conversational AI tutorial](/tutorials/voice-ai-examples/elevenlabs-conversational-ai).

## Speech-to-text

```json
{
  "verb": "gather",
  "input": ["speech"],
  "actionHook": "/gather",
  "recognizer": {
    "vendor": "elevenlabs",
    "language": "en",
    "elevenlabsOptions": {
      "commitStrategy": "vad",
      "vadSilenceThresholdSecs": 0.8
    }
  }
}
```

### Models

The model is set on the speech credential in the portal. It cannot be changed on the verb.

| Model | Notes |
|---|---|
| `scribe_v2_realtime` | The only realtime model jambonz offers. Also used when the credential has no model saved. |

### Options

Pass these in `recognizer.elevenlabsOptions`.

<ParamField path="commitStrategy" type="string" required={false}>
  How ElevenLabs decides a transcript is final. `vad` commits when voice activity detection hears the caller stop. `manual` waits for an explicit commit. Default: `vad`.
</ParamField>

<ParamField path="vadSilenceThresholdSecs" type="number" required={false}>
  (`vad` only) Seconds of silence that end a segment.
</ParamField>

<ParamField path="vadThreshold" type="number" required={false}>
  (`vad` only) Voice activity detection threshold.
</ParamField>

<ParamField path="minSpeechDurationMs" type="number" required={false}>
  (`vad` only) Shortest speech, in milliseconds, that counts as speech.
</ParamField>

<ParamField path="minSilenceDurationMs" type="number" required={false}>
  (`vad` only) Shortest silence, in milliseconds, that counts as the end of speech.
</ParamField>

<ParamField path="includeTimestamps" type="boolean" required={false}>
  Ask ElevenLabs for word-level timestamps. Default: `false`.
</ParamField>

<ParamField path="enableLogging" type="boolean" required={false}>
  Accepted, but currently has no effect: jambonz does not send it to ElevenLabs.
</ParamField>

### Notes

- **Keep `commitStrategy` at `vad`.** jambonz sends a commit only when recognition stops, so with `manual` a `gather` gets no final transcript while the caller is speaking.
- **`language` is trimmed.** jambonz sends only the part before any hyphen, so `en-US` is sent as `en`. The portal lists ElevenLabs languages by their three-letter codes, such as `eng`.
- **`hints` has no effect.** jambonz does not send hints to ElevenLabs.
- **Audio is sent at 8 kHz**, whatever the call's codec.
- **The API region does not apply to speech-to-text.** Speech-to-text always connects to `api.elevenlabs.io`. The credential's EU or India data residency setting applies to text-to-speech only.

## Text-to-speech

```json
{
  "verb": "say",
  "text": "Thanks for calling, how can I help you today?",
  "synthesizer": {
    "vendor": "elevenlabs",
    "voice": "21m00Tcm4TlvDq8ikWAM",
    "options": {
      "voice_settings": {
        "stability": 0.5,
        "similarity_boost": 0.5,
        "use_speaker_boost": true
      }
    }
  }
}
```

Set `synthesizer.voice` to an ElevenLabs voice ID, not a voice name. The portal lists the voices on your ElevenLabs account; see also ElevenLabs' [voice library](https://elevenlabs.io/app/voice-library).

### Models

The model is set on the speech credential. To use a different model for one verb, set `synthesizer.options.model_id`.

The portal fetches the model list from your ElevenLabs account. If that fails, it offers these:

| Model | Notes |
|---|---|
| `eleven_flash_v2_5` | Default for new speech credentials. |
| `eleven_flash_v2` | |
| `eleven_multilingual_v2` | |
| `eleven_turbo_v2_5` | Deprecated by ElevenLabs. |
| `eleven_turbo_v2` | Deprecated by ElevenLabs. |
| `eleven_multilingual_v1` | Deprecated by ElevenLabs. |
| `eleven_monolingual_v1` | Deprecated by ElevenLabs. |
| `eleven_multilingual_sts_v2` | |
| `eleven_english_sts_v2` | |

There is no fallback model: a request with no model fails. `eleven_v3` is HTTP-only at ElevenLabs, so it works with `say` but not with TTS streaming.

### Options

Pass these in `synthesizer.options`, or save them on the speech credential under **Extra Options**. Most of them go in a nested `voice_settings` object, matching ElevenLabs' own API. The portal fills new credentials with `stability` and `similarity_boost` of `0.5`, `use_speaker_boost` of `true` and `optimize_streaming_latency` of `3`.

<ParamField path="model_id" type="string" required={false}>
  The model for this verb, overriding the credential's.
</ParamField>

<ParamField path="voice_id" type="string" required={false}>
  (`say` only) A voice ID that overrides `synthesizer.voice`.
</ParamField>

<ParamField path="voice_settings.stability" type="number" required={false}>
  `0.0` to `1.0`. Lower values make delivery more varied and expressive; higher values make it more consistent and monotone.
</ParamField>

<ParamField path="voice_settings.similarity_boost" type="number" required={false}>
  `0.0` to `1.0`. How closely the output tracks the original voice.
</ParamField>

<ParamField path="voice_settings.style" type="number" required={false}>
  Style exaggeration. Raising it increases expressiveness but costs latency, and can make the voice unstable at high values.
</ParamField>

<ParamField path="voice_settings.use_speaker_boost" type="boolean" required={false}>
  Improves similarity to the original speaker at a small latency cost.
</ParamField>

<ParamField path="voice_settings.speed" type="number" required={false}>
  Speaking rate.
</ParamField>

<ParamField path="pronunciation_dictionary_locators" type="array" required={false}>
  (TTS streaming only) Pronunciation dictionaries to apply, in ElevenLabs' locator form. Not applied to `say`.
</ParamField>

<ParamField path="optimize_streaming_latency" type="number" required={false}>
  Accepted, but currently has no effect: jambonz does not send it to ElevenLabs.
</ParamField>

<Note>
`stability` and `style` pull against each other. If you raise `style` for expressiveness and the voice starts to wander or produce artifacts, raise `stability` rather than lowering `style` back down.
</Note>

### Notes

- **Verb options replace credential options on `say`.** If `synthesizer.options` has any fields, the credential's Extra Options are not used for that `say`. With TTS streaming the two are merged, and the verb wins where both set a field.
- **`language` is mostly ignored.** jambonz sends it only for TTS streaming with `eleven_turbo_v2_5`. The voice and model determine the language otherwise.
- **`previous_text` and `next_text` have no effect.** jambonz does not send them to ElevenLabs.
- **Audio is requested at 16 kHz** and resampled to the call's rate.
- **Streaming and barge-in.** ElevenLabs supports [TTS streaming](/guides/features/tts-streaming) with character-level alignment. Its protocol has no cancel message, so on barge-in jambonz drops the buffered audio and reconnects.
