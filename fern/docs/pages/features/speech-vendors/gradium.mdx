title: Gradium
subtitle: Text-to-speech models, options and notes for Gradium.

jambonz supports [Gradium](https://gradium.ai) for **text-to-speech** (vendor `gradium`), both for `say` and for [TTS streaming](/guides/features/tts-streaming). Gradium has no speech-to-text in jambonz.

To create a credential, make an API key in Gradium's console (it begins with `gsk_`), then add it in the portal under **Account → Speech → Add speech service → Gradium**. The portal's **Test** button checks the key by listing your voices and synthesizing a short phrase.

## Text-to-speech

```json
{
  "verb": "say",
  "text": "Thanks for calling, how can I help you today?",
  "synthesizer": {
    "vendor": "gradium",
    "language": "en",
    "voice": "YTpq7expH9539ERJ",
    "options": {
      "json_config": {
        "temp": 0.7,
        "padding_bonus": -1.0
      }
    }
  }
}
```

### Models

Pick the model on the speech credential in the portal, or override it for one verb with `synthesizer.options.model_id`.

| Model | Notes |
|---|---|
| `default` | Gradium's current model. Used when no model is set. |
| `gradium-tts-beta` | |

`voice` is a Gradium voice ID. The portal fetches the voice list from your account, so your custom and cloned voices appear next to the catalog voices. Gradium groups voices by bare language code (`en`, `de`, `fr`, `es`, `pt`), not by locale, so use `en`, not `en-US`. For the catalog, see [Gradium's documentation](https://docs.gradium.ai).

### Options

Pass these in `synthesizer.options`.

<ParamField path="json_config" type="object" required={false}>
  Voice settings, sent to Gradium as-is. jambonz converts the object to the JSON string Gradium expects. Fields documented by Gradium include:

  - `temp`: sampling temperature, `0.0` to `1.5`. `0.0` is deterministic; higher values give more varied delivery.
  - `cfg_coef`: voice similarity. Higher values stay closer to the target voice; very high values can add artifacts.
  - `padding_bonus`: speaking rate, `-5.0` to `5.0`. Negative values are faster and positive values are slower, the opposite of most vendors' speed controls.
  - `rewrite_rules`: a language code, e.g. `"en"`, that turns on Gradium's language-specific text rewriting before synthesis.

  See [Gradium's voice settings](https://docs.gradium.ai/guides/voice-settings).
</ParamField>

<ParamField path="pronunciation_id" type="string" required={false}>
  ID of a pronunciation dictionary in your Gradium account. It goes at the top level of `options`, next to `json_config`, not inside it.
</ParamField>

<ParamField path="model_id" type="string" required={false}>
  Model to use for this verb instead of the credential's.
</ParamField>

### Notes

- **Extra Options on the credential apply to streaming only.** For `say`, jambonz reads `json_config` and `pronunciation_id` from the verb and ignores the credential's Extra Options. When streaming, the two are merged and the verb wins.
- **A verb's `json_config` replaces the credential's.** The merge is by top-level key, so setting `json_config` on the verb drops every field of the credential's `json_config`.
- **Portal defaults.** When you turn on Extra Options, the portal fills in `temp: 0.7`, `cfg_coef: 2.0` and `padding_bonus: 0.0`. These are starting values, not defaults jambonz applies.
- **Sample rates.** jambonz asks Gradium for audio at the call's own rate when Gradium offers it (8, 16, 22.05, 24, 44.1 or 48 kHz), so a G.711 call needs no resampling. Other rates get 16 kHz audio, which jambonz resamples.
- **Streaming.** One websocket connection serves every turn of the call, so there is no connection setup in front of each turn's first audio.
- **Barge-in.** Gradium has no cancel message. jambonz ends the interrupted stream and discards any of its audio still arriving.
- **Word timestamps.** Gradium returns word timing while streaming, so jambonz can track how much of a response the caller heard. See [TTS streaming](/guides/features/tts-streaming).
