This document outlines the SIP and RTP Interoperability details of the [jambonz.cloud](https://jambonz.cloud) hosted system.

# SIP specification

The SIP signaling address(es) for jambonz.cloud are shown below.  You should make sure your firewall allows traffic from and to these addresses.
- 54.236.168.131

The following protocols are supported:
- UDP, port 5060
- TCP, port 5060
- TLS, port 5061
- SIP over websockets (for WebRTC clients), port 8443

As part of your jambonz.cloud account you have a dedicated SIP FQDN that you chose during signup; e.g. something along the lines of "mysubdomain.sip.jambonz.cloud". 

You should have your carriers send to that FQDN; or, if they do not support sending INVITEs to an FQDN, to the static IP address(es) above.  

If you are registering a SIP client device to jambonz.cloud, then you must REGISTER with your FQDN as the sip realm.

# RTP specification

The RTP media address(es) on jambonz.cloud are shown below.  You should make sure your firewall allows traffic from and to these addresses.
- 54.144.249.44
- 3.218.246.146

The RTP port range on jambonz.cloud is 40000-60000/udp.

The following codecs are supported:
- PCMU
- PCMA
- G722
- OPUS
