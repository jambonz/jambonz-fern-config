The jambonz WebRTC SDK enables browser and mobile applications to make and receive voice calls through a jambonz SBC using SIP over WebSocket.

It supports **Web (React)** and **React Native (iOS + Android)** with a unified API. JsSIP is used internally for SIP signaling but is completely hidden from consumers.

## Installation

#### Web (React)

```bash
npm install @jambonz/client-sdk-web
```

#### React Native

```bash
npm install @jambonz/client-sdk-react-native react-native-webrtc
```

For iOS, also run:
```bash
cd ios && pod install && cd ..
```

## Quick Start

Connect to your jambonz SBC and make a call in a few lines:

```js
import { createJambonzClient } from '@jambonz/client-sdk-web';
// or: import { createJambonzClient } from '@jambonz/client-sdk-react-native';

const client = createJambonzClient({
  server: 'wss://sbc.example.com:8443',
  username: 'user1',
  password: 'pass123',
});

await client.connect();

// Make a call
const call = client.call('+15551234567');
call.on('accepted', () => console.log('Call connected'));
call.on('ended', () => console.log('Call ended'));
```

## Call Types

The SDK supports four types of outbound calls, matching jambonz SBC routing conventions:

```js
// Call a phone number or SIP URI
const call = client.call('+15551234567');

// Call another registered SIP user
const call = client.callUser('alice');

// Take a call from a queue
const call = client.callQueue('support');

// Join a conference room
const call = client.callConference('standup-meeting');

// Call a jambonz application by its SID
const call = client.callApplication('your-application-sid');
```

## Receiving Incoming Calls

```js
client.on('incoming', (call) => {
  console.log('Incoming call from:', call.remoteIdentity);
  call.answer();   // or call.hangup() to decline
});
```

## In-Call Controls

Once a call is active, you have full control:

```js
// Mute / unmute
call.mute();
call.unmute();
call.toggleMute();

// Hold / resume
call.hold();
call.unhold();

// Send DTMF tones
call.sendDTMF('1');
call.sendDTMF('#');

// Transfer the call (blind)
call.transfer('sip:other-user@domain');

// Attended transfer (connect two active calls)
call.attendedTransfer(otherCall);

// Hang up
call.hangup();
```

## Call Options

Every call method accepts optional configuration:

```js
const call = client.call('+15551234567', {
  // Custom SIP headers
  headers: { 'X-Customer-Id': '12345' },

  // Auto-hangup if no answer within 30 seconds
  noAnswerTimeout: 30,

  // Prefer specific audio codecs
  preferredCodecs: ['opus', 'PCMU'],

  // Enable server-side recording (sends X-Record-Call header)
  record: true,

  // Custom ICE/STUN/TURN servers
  pcConfig: {
    iceServers: [{ urls: 'stun:stun.l.google.com:19302' }],
  },
});
```

## Call Quality Monitoring

Monitor call quality metrics in real-time:

```js
// One-time snapshot
const stats = await call.getStats();
console.log(stats.roundTripTime, stats.jitter, stats.packetLoss);

// Continuous monitoring (every 2 seconds)
call.startQualityMonitoring(2000);
call.on('qualityStats', (stats) => {
  console.log(`RTT: ${stats.roundTripTime}ms, Jitter: ${stats.jitter}ms`);
});
call.stopQualityMonitoring();
```

## SIP Messaging

Send and receive SIP MESSAGE (text):

```js
// Send
client.sendMessage('sip:alice@domain', 'Hello!');
client.sendMessage('sip:alice@domain', JSON.stringify({ type: 'ping' }), 'application/json');

// Receive
client.on('message', ({ from, body, contentType }) => {
  console.log(`Message from ${from}: ${body}`);
});
```

## React Hooks

Both packages export React hooks for declarative integration:

```tsx
import { useJambonzClient, useCall } from '@jambonz/client-sdk-web';

function Phone() {
  const { state, isRegistered, connect, disconnect, error } = useJambonzClient({
    server: 'wss://sbc.example.com:8443',
    username: 'user1',
    password: 'pass123',
  });

  const {
    call, state: callState, isMuted, isHeld, isActive,
    makeCall, hangup, toggleMute, toggleHold, sendDtmf,
    incomingCaller, answerIncoming, declineIncoming,
  } = useCall(client);

  return (
    <div>
      <p>Status: {state}</p>
      <button onClick={connect}>Connect</button>
      <button onClick={() => makeCall('+15551234567')}>Call</button>
      {isActive && <button onClick={hangup}>Hang Up</button>}
    </div>
  );
}
```

## Audio Device Management

Enumerate and switch audio devices:

```js
import { JambonzAudioManager } from '@jambonz/client-sdk-web';

const audioManager = new JambonzAudioManager(platform);

// List devices
const mics = await audioManager.getMicrophones();
const speakers = await audioManager.getSpeakers();

// Switch output device (web: deviceId, React Native: 'speaker' or 'earpiece')
await audioManager.setOutputDevice(speakers[0].deviceId);
```

## Multiple Simultaneous Calls

The client tracks all active calls:

```js
console.log(client.callCount);  // Number of active calls

// Iterate all active calls
for (const [id, call] of client.calls) {
  console.log(`Call ${id}: ${call.state}`);
}
```

## Client Events

```js
client.on('registered', () => {});          // SIP registration succeeded
client.on('unregistered', () => {});        // SIP registration removed
client.on('registrationFailed', (err) => {});  // Registration failed
client.on('incoming', (call) => {});        // Incoming call received
client.on('stateChanged', (state) => {});   // Client state changed
client.on('connected', () => {});           // WebSocket connected
client.on('disconnected', () => {});        // WebSocket disconnected
client.on('message', (msg) => {});          // SIP MESSAGE received
client.on('error', (err) => {});            // Error occurred
```

## Call Events

```js
call.on('accepted', () => {});              // Call answered
call.on('progress', () => {});              // Call ringing (180/183)
call.on('ended', (cause) => {});            // Call ended
call.on('failed', (cause) => {});           // Call failed to connect
call.on('stateChanged', (state) => {});     // Call state changed
call.on('hold', (held) => {});              // Hold state changed
call.on('mute', (muted) => {});             // Mute state changed
call.on('dtmf', (tone) => {});              // DTMF tone received
call.on('transferred', () => {});           // Transfer succeeded
call.on('transferFailed', (err) => {});     // Transfer failed
call.on('qualityStats', (stats) => {});     // Quality metrics update
```

## Client Configuration

```js
const client = createJambonzClient({
  server: 'wss://sbc.example.com:8443',  // WebSocket URL (required)
  username: 'user1',                       // SIP username (required)
  password: 'pass123',                     // SIP password (required)
  displayName: 'John Doe',                // Display name for callee
  realm: 'example.com',                   // SIP realm (defaults to server hostname)
  autoRegister: true,                      // Auto-register on connect (default: true)
  registerExpires: 300,                    // Registration expiry in seconds
  userAgent: 'my-app/1.0',               // Custom SIP User-Agent header
});
```
